# Python Data Programming Final Project

This repository contains my final project for the Python Data Programming course.  
The project uses **Python modules**, **SQLite**, and a simple UI to simulate a small data system.

## 📁 Project Files
- **business.py** – Handles business logic  
- **db.py** – Database interaction and queries  
- **ui.py** – User interface for running the program  
- **Final.sqlite** – SQLite database file used by the project  
- **/final_docs** – Project documentation and design notes  
- **/__pycache__** – Auto-generated Python cache folder  

## 🎯 Purpose of the Project
This final project demonstrates:
- Working with Python functions and modules  
- Creating and managing a SQLite database  
- Reading and writing data  
- Organizing a project into logical Python files
